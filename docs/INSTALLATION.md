# Instalação e atualização
```bash
git clone https://github.com/mxcapellani/pessoas-realistas-ai-ultimate.git
cd pessoas-realistas-ai-ultimate
```
Copiar `.agents/skills/pessoas-realistas-ai-ultimate` inteira para o projeto alvo; descoberta depende do host. Carregar SKILL.md explicitamente quando necessário. Não instala editor ou integração.
Atualizar preservando alterações locais, consultar CHANGELOG e repetir os testes. Não renumerar IDs existentes ao acrescentar registros. Catálogo literal é fonte operacional; adaptações não sobrescrevem originais. Python padrão para busca; PyYAML somente para validação de desenvolvimento.
